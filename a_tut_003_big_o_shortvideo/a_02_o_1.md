## O(1): Constant Time

**O(1)** means an operation takes about the same amount of time every time,
regardless of how much data there is.

Example in JavaScript:

```javascript
const fruits = ["apple", "banana", "orange", "mango"];

console.log(fruits[2]); // orange
```

JavaScript goes directly to index `2`. It does not need to check every item,
so accessing an array item by its index is **O(1)**.
