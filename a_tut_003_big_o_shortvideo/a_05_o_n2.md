## O(n²): Quadratic Time

**O(n²)** means the work increases much faster as the input grows. If the input doubles, the program may do about four times as much work.

A common example is a loop inside another loop:

```javascript
const numbers = [1, 2, 3, 4];

for (let i = 0; i < numbers.length; i++) {
  for (let j = 0; j < numbers.length; j++) {
    console.log(numbers[i], numbers[j]);
  }
}
```

For 4 numbers, the inner code runs $4 \times 4 = 16$ times.

For 100 numbers, it runs $100 \times 100 = 10{,}000$ times. That is why **O(n²)** gets much slower as the input grows.
